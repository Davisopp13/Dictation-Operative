# PWA V2

## Using the additions

- **Workspace tools** in the header manages collection suggestions, personal vocabulary,
  and up to 30 custom voice templates. Changes are stored under the signed-in account.
  Export/import these tools separately as JSON; importing stages them for review before saving.
- Open a thought to assign a collection and up to 12 tags. Type a new collection directly
  or choose a suggestion. Library filters match collection and tag together with search
  and pins. Tags are case-insensitive. Library backups preserve these labels, including
  across accounts; V1 backups import with empty labels. Removing a collection suggestion
  does not delete or relabel thoughts already using it.
- Pick a voice template before capture, or apply one to a saved thought. Templates save a
  new text version, preserving the original. Preferred spellings are supplied to both
  transcription and writing requests; they are hints, not guaranteed literal replacements.
  Groq documents a 224-token transcription prompt budget: the app caps vocabulary at 700
  characters but non-English entries can tokenize longer. Put the most useful words first.
- **Unfinished recordings on this device** offers recovery, download, and discard. A failed
  recording also offers Retry and Keep for later. Recovery retains note/reply/prompt context
  or the existing thought ID for Add More. Recovery saves original words; apply the desired
  template in the editor afterward, avoiding repeated AI rewrites after interrupted saves.
- After an initial online sign-in, the cached offline screen supports new recordings without
  a network. Reopen the workspace online and choose Recover to library. Library access,
  transcription, and AI still require internet. Existing Sync handles phone-to-Mac clipboard
  handoff; this release does not change its platform support.

## Recording guarantees and limits

Audio chunks are committed to IndexedDB about once a second, with the recording ID, owner,
MIME type, and intended destination. The transcript is saved locally before the library
write. Audio is removed only after a successful library save or explicit discard. Stable
IDs make creation and Add More retries duplicate-safe. Web Locks serialize recording and
recovery across same-origin tabs; an active recording cannot be recovered or deleted by
another tab. A deleted append destination produces an error and retains the audio for download.

Five minutes / 20 MB per recording, at most 20 unfinished recordings and approximately
100 MB across accounts on this browser. Storage failures stop capture and offer download;
the online recorder retains its full in-memory audio as a fallback. The offline shell can
recover only chunks that reached storage if a write fails. A crash can lose the final chunk
or leave an incomplete MP4/WebM container that the transcription provider cannot decode.
Download remains available; no claim of guaranteed crash-proof audio is made.

Local recordings are not encrypted by the app at rest. Browser data clearing, private mode,
or storage eviction can erase them; persistent storage is requested where available but
not guaranteed. Offline capture remembers the last signed-in account on that browser.
Sign in to that account to recover; account switching never automatically uploads another
account's audio. Shared-device users should discard/download unfinished recordings before
clearing site data. No continuous background recording or offline speech model is included.

Requires HTTPS (localhost is supported for development), MediaRecorder, IndexedDB, and Web
Locks in a current Safari/Chrome-class browser. iOS backgrounding stops capture; restart
recovery on a physical iPhone and real provider recognition quality remain acceptance checks.

## Architecture and validation

- Additive Drizzle migration `0001_milky_blindfold.sql`: clip metadata and owner-scoped tools.
- Revision-checked tools and clip writes return 409 on stale changes.
- `lib/workspace-tools.ts`: validation and D1 persistence, separate from transcription.
- `public/recording-store.js`: shared IndexedDB adapter for online and offline capture.
- `lib/recordings.ts`: recover-to-library flow; `components/do/recovery.tsx`: user actions.
- Static service worker caches no authenticated HTML, transcripts, or API responses.

Automated tests cover real Miniflare D1 migration and ownership, concurrent tools writes,
metadata filtering and backup roundtrips, bounded preferences, provider request contracts,
IndexedDB chunk ordering/idempotency, reopen persistence, account separation, quotas, and
removal. Existing V1 API/version/credential tests remain in the suite. Tests use synthetic
provider responses; they do not spend the user's Groq quota.

Native keyboards, billing, meeting bots, and broad third-party integrations remain later
work. This V2 implements the saved PWA roadmap; it does not add an iOS App Store binary.

Provider reference: https://console.groq.com/docs/speech-to-text
